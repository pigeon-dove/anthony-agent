## 2026-04-08

### 上下文压缩优化
- **豁免名单机制**：将工具压缩逻辑从「白名单内才压缩」改为「豁免名单内不压缩」
  - 旧逻辑：`_COMPACTABLE_TOOLS` 白名单，只有 `read_file`、`bash` 等查询类工具才压缩
  - 新逻辑：`_SKIP_COMPACT_TOOLS` 豁免名单，`write_file`、`edit_file`、`multi_edit` 不压缩，其余全部压缩
  - 目的：未来接入 MCP 工具时，新工具默认被压缩，无需手动维护白名单
- **保留轮次调整**：auto_compact 保留最近 3 轮完整对话（从 1 轮改为 3 轮）
- **降级策略**：对话轮次不足时逐步降级（3→2→1），无法拆分则仅做 micro_compact
- **去除 200 字阈值**：移除了「少于 200 字不压缩」的逻辑
- **文档整理**：清理旧文档，精简为 roadmap + 开发日志两个文件
