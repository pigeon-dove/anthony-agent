### 1. 项目架构讨论

与 AI 助手进行了头脑风暴，讨论了以下关键问题：

#### 讨论的问题与决策

| 问题 | 选项 | 最终决策 | 理由 |
|------|------|----------|------|
| 代码组织方式 | `src/` 目录 vs 扁平结构 | **`src/` 目录** | 层次清晰，源码与配置/文档分离，适合教学 |
| 工具文件组织 | 按类型分子目录 vs 全部平铺 | **全部平铺** | 工具数量适中（9个），平铺更直观 |
| 文档组织 | work-logs 方案 | **`docs/work-logs/`** | 文件名带日期时间+名字，便于追溯 |
| Skill 文件位置 | 内部 vs 外部 | **外部（根目录 `skills/`）** | 与加载逻辑分离，用户扩展更方便 |
| 测试 | 现在写 vs 后续补充 | **暂时跳过** | 先聚焦核心功能 |
| 项目名称 | - | **anthony-agent** | 保持现有名称 |

### 3. 项目核心模块划分

确定了以下核心模块：

1. **Client 层** (`src/client/`) - OpenAI SDK 封装，流式输出
2. **Agent 核心** (`src/agent/`) - Agent Loop + Sub Agent
3. **工具系统** (`src/tools/`) - 9 个内置工具，平铺结构
4. **MCP 集成** (`src/mcp/`) - 外部工具协议接入
5. **Skill Loading** (`src/skills/`) - 外部指令集加载
6. **上下文管理** (`src/context/`) - Context Compact
7. **记忆持久化** (`src/memory/`) - JSONL 存储
8. **任务系统** (`src/task/`) - 任务管理
